# UI Contract

Status: BASELINE DEFINED — product/design/accessibility review required

The product uses a calm clinical editorial direction: warm neutral surfaces, near-black text, one restrained teal/blue
action colour, semantic status colours, self-hosted type, 4/8 spacing, 8–12 px radii, borders and whitespace before
decoration, and direct sentence-case copy.

## Screen contract

Every route defines its user, job, permission, data class, primary action, secondary action, and all states: loading,
empty, validation, server error, stale/session expired, success, and destructive confirmation. Use semantic landmarks,
native controls, visible focus, keyboard operation, 200% zoom, reduced motion, and a text/table alternative for every
chart.

## Prohibited patterns

No gradient/blob hero, glassmorphism, excessive shadows, pill-shaped everything, fake logos/testimonials/counters,
decorative dashboard metrics, rainbow charts, stock wellness imagery, emoji icons, or unverified security/compliance/
clinical outcome claims. Current prototype pages are wireframes and must not be copied as visual references.

Clinical privacy, consent, cancellation, complaint and urgent-help content must be available in English and Bahasa
Melayu. Administrative and marketing surfaces may be English-only at launch. Language selection must preserve task state
and never silently fall back during consent.

## Required review evidence

For each completed journey: screenshots at 390/768/1440 CSS px, keyboard pass, axe pass, contrast, reduced motion, zoom,
visual regression review, realistic synthetic copy, and a human product/design sign-off.
